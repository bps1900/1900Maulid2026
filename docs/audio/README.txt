Taruh file musik latar kamu di sini dengan nama persis: soundtrack.mp3

Rekomendasi cari musik instrumental "arabic desert" / "oud" / "padang pasir"
yang BEBAS ROYALTI (free license) di situs seperti:
- pixabay.com/music (gratis, no attribution required)
- YouTube Audio Library (via studio.youtube.com)
- freesound.org / soundcloud.com bagian Creative Commons

Hindari pakai lagu berhak cipta (dari penyanyi/label) karena bisa
bermasalah kalau website ini dipakai publik/dibagikan.

Setelah dapat file mp3-nya:
1. Rename jadi: soundtrack.mp3
2. Taruh persis di folder ini (public/audio/soundtrack.mp3)
3. Restart server (npm start), lalu refresh browser
